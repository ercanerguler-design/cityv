# City-V — Akıllı Şehir İzleme Platformu

**Şehirleri Zekâyla Yönet, Geleceği Birlikte İnşa Et**

City-V; **İstanbul, Ankara, İzmir, Antalya ve Bursa**'da **trafik, enerji, atık, güvenlik ve çevreyi** tek platformdan izler.

## Özellikler

| Modül | Açıklama |
|---|---|
| 🚦 **Trafik** | Yoğunluk, ortalama hız ve aktif kaza sayısı |
| ⚡ **Enerji** | Tüketim, yenilenebilir enerji payı ve şebeke durumu |
| ♻️ **Atık** | Günlük atık üretimi, geri dönüşüm oranı ve doluluk durumu |
| 🔒 **Güvenlik** | Aktif kamera sayısı, alarm durumu ve ortalama müdahale süresi |
| 🌿 **Çevre** | Hava kalitesi (AQI), gürültü seviyesi ve sıcaklık |

## Desteklenen Şehirler

- İstanbul
- Ankara
- İzmir
- Antalya
- Bursa

## Kullanım

`index.html` dosyasını bir tarayıcıda açın. Veriler 5 saniyede bir canlı olarak güncellenir.

```
cityv/
├── index.html   # Ana sayfa
├── styles.css   # Stiller
└── app.js       # Veri ve mantık katmanı
```
